# Третий чистый набор `clean3/`

Чистый набор №3 (пятый вымышленный набор после `synthetic/`, `holdout/`, `clean/` и `clean2/`) (номера `D95xxxxxxx-NN`, стороны, адреса и формулировки придуманы и не повторяют `clean/` и `clean2/`). Набор написан без чтения кода системы, конфигурации, правил шлюза, промптов, модульных тестов и текстов наборов `synthetic/` и `holdout/`; опора — договорная практика (ГК РФ, типовые договоры). Итог кода `main` снят на нём один раз; после этого 10 его ошибок сверены с текстом, и он прогнан на не принятом коде p9 (`docs/experiments/p9.md`). По его ошибкам правила не настраивались, но для следующих правок он уже не чистый.

## Состав

- `sources/<кластер>/*.md` — тексты документов: абзац на строку, строка `<!-- page -->` начинает новую страницу, остальные `<!-- ... -->` — комментарии.
- `build/` — собранные файлы (текстовые PDF, два скана с шумом, DOCX). Имена файлов частью неинформативные: из них ничего нельзя выводить.
- `golden.yaml` — эталон в формате `docs/golden_guide.md`. Решения по спорным местам записаны в его шапке.

## Сборка

```bash
uv run python scripts/make_clean3.py
```

Сборка воспроизводима байт в байт: `doc_id` (первые 12 знаков sha256 файла) от запуска к запуску не меняются. Если правка текста меняет `doc_id`, скрипт сам заменяет старый id на новый в `golden.yaml`. Проверки набора: эталон грузится, цитаты есть на страницах, все файлы размечены, номера только `D95…`, две сборки совпадают.

```bash
uv run pytest tests/synthetic/test_clean_set.py
```

## Замер

Дата прогона `--as-of 2026-10-30`; эталон также задаёт состояние на 2027-02-01.

```bash
uv run contract-analyst analyze clean3/build --as-of 2026-10-30 --out runs/clean3
```

```bash
uv run contract-analyst eval golden runs/clean3/<прогон> --golden clean3/golden.yaml
```
