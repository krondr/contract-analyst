# Второй чистый набор `clean2/`

Четвёртый набор вымышленных документов (номера `D96xxxxxxx-NN`, стороны, адреса и формулировки придуманы и не повторяют `clean/`). Это финальная независимая проверка. Набор написан без чтения кода системы (кроме схемы и загрузчика эталона), правил шлюза, промптов, модульных тестов и текстов наборов `synthetic/` и `holdout/`. На нём меряется только итог, один раз: по его ошибкам правила не настраиваются. Если правило всё же поменяли из-за ошибки на этом наборе, набор перестаёт быть чистым.

## Состав

- `sources/<кластер>/*.md` — тексты документов: абзац на строку, строка `<!-- page -->` начинает новую страницу, остальные `<!-- ... -->` — комментарии.
- `build/` — собранные файлы (текстовые PDF, скан с шумом, DOCX). Имена файлов частью неинформативные: из них ничего нельзя выводить.
- `golden.yaml` — эталон в формате `docs/golden_guide.md` (схема `src/contract_analyst/eval/golden.py`). Решения по спорным местам записаны в его шапке.

## Сборка

```bash
uv run python scripts/make_clean2.py
```

Сборка воспроизводима байт в байт: `doc_id` (первые 12 знаков sha256 файла) от запуска к запуску не меняются. Если правка текста меняет `doc_id`, скрипт сам заменяет старый id на новый в `golden.yaml`. Проверки набора: эталон грузится, цитаты есть на страницах, все файлы размечены, номера только `D96…`, две сборки совпадают.

```bash
uv run pytest tests/synthetic/test_clean_set.py
```

## Замер

Дата прогона `--as-of 2026-10-30`; эталон также задаёт состояние на 2027-02-01.

```bash
uv run contract-analyst analyze clean2/build --as-of 2026-10-30 --out runs/clean2
```

```bash
uv run contract-analyst eval golden runs/clean2/<прогон> --golden clean2/golden.yaml
```

## Документы и явления

«Начало» — `effective_from` документа: с какой даты он действует.

Кластер `promo`: партнёрское продвижение, сеть кофеен раздаёт промокоды онлайн-кинотеатра.

| Файл | Документ | Явления |
|---|---|---|
| `promo/Договор Зерно и Пар.pdf` | договор D961000001-01, 3 стр. | начало не с подписания: «вступает в силу 01 мая 2025 года» в последнем пункте; таблица плана (активации и доля вида подписки — не ставки) рядом с таблицей вознаграждения; НДС только в шапке таблицы («без налога на добавленную стоимость»); доплата за выполнение плана за каждую активацию — ставка («НДС … исчисляется дополнительно»); штраф в процентах от вознаграждения за месяц и штраф «за каждое нарушение» — не ставки; виды подписки, адреса кофеен |
| `promo/ДС к договору.pdf` | ДС D961000002-01, 2 стр. | длинное тире в номере договора в шапке; новая редакция статьи с планом (плановые суммы с копейками — не ставки); новая таблица вознаграждения с копейками, НДС только в шапке («включая налог на добавленную стоимость»); доплата «41 рубль 25 копеек», налог «сверх неё»; пункт «применяются к Активациям, совершённым с 01 января 2026 года» (даты изменений, не операция); начало «со дня подписания Сторонами» в заключительном пункте (не операция) |
| `promo/изменения август.pdf` | ДС D961000003-01, 1 стр. | изменение строки таблицы из другого допсоглашения (цель — пункт D961000002-01); новая сумма «вводится с …» позже подписания; дополнение договора пунктом со штрафом в двукратном размере вознаграждения — не ставка; начало «с момента его подписания» |
| `promo/Документ (2).docx` | ДС D961000004-01, DOCX | обычный документ: новая редакция сроков оплаты и канала обмена документами; о начале не сказано ничего (начало `absent`) |
