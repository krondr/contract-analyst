# Чистый оценочный набор `clean/`

Третий набор вымышленных документов (номера `D97xxxxxxx-NN`, стороны, адреса и формулировки придуманы). Он написан до раунда правок p7, без чтения правил шлюза, промптов, модульных тестов и текстов наборов `synthetic/` и `holdout/`. На нём меряется только итог раунда, один раз: по ошибкам этого набора правила не настраиваются. Если правило всё же поменяли из-за ошибки на этом наборе, набор перестаёт быть чистым, и для следующего замера нужен новый.

## Состав

- `sources/<кластер>/*.md` — тексты документов: абзац на строку, строка `<!-- page -->` начинает новую страницу, остальные `<!-- ... -->` — комментарии.
- `build/` — собранные файлы (текстовые PDF, скан с шумом, DOCX). Имена файлов частью неинформативные: из них ничего нельзя выводить.
- `golden.yaml` — эталон в формате `docs/golden_guide.md` (схема `src/contract_analyst/eval/golden.py`). Решения по спорным местам записаны в его шапке.

## Сборка

```bash
uv run python scripts/make_clean.py
```

Сборка воспроизводима байт в байт: `doc_id` (первые 12 знаков sha256 файла) от запуска к запуску не меняются. Если правка текста меняет `doc_id`, скрипт сам заменяет старый id на новый в `golden.yaml`. Проверки набора (эталон грузится, цитаты есть на страницах, все файлы размечены, номера только `D97…`, две сборки совпадают):

```bash
uv run pytest tests/synthetic/test_clean_set.py
```

## Замер

Дата прогона `--as-of 2026-10-30`; эталон также задаёт состояние на 2027-02-01.

```bash
uv run contract-analyst analyze clean/build --as-of 2026-10-30 --out runs/clean
```

```bash
uv run contract-analyst eval golden runs/clean/<прогон> --golden clean/golden.yaml
```

## Документы и явления

Кластер `agency` — агентский договор (коммерческое представительство):

| Файл | Документ | Явления |
|---|---|---|
| `agency/Агентский договор Ориентир.pdf` | договор D971000001-01, 3 стр. | таблица плановых показателей (подключения и выручка по кварталам — не ставки) рядом с таблицей вознаграждения; НДС только в шапке таблицы вознаграждения («включая НДС»); премия за каждого абонента при выполнении плана — ставка; штраф «за каждое нарушение» и штраф в процентах от вознаграждения за месяц — не ставки; торговые точки, группы тарифов |
| `agency/ДС_2026.pdf` | ДС D971000002-01, 2 стр. | новый план на год таблицей (не ставки, суммы с копейками); новая таблица вознаграждения, НДС только в шапке («НДС не включён»); суммы с копейками («245 рублей 50 копеек», «712,50»); «сверх того НДС»; изложение раздела в новой редакции; пункт о дате, с которой применяются изменённые условия (не отдельное изменение); заключительный пункт о вступлении в силу (не изменение) |
| `agency/доп3.pdf` | ДС D971000003-01, 1 стр. | длинное тире внутри собственного номера в заголовке; изменение пункта другого допсоглашения (цель — пункт D971000002-01); дополнение договора новым пунктом; штраф в кратном размере вознаграждения — не ставка; «распространяет своё действие на отношения, возникшие с …» раньше даты подписания; «руб. … коп.»; «включает НДС» |

Кластер `lease` — аренда нежилого помещения:

| Файл | Документ | Явления |
|---|---|---|
| `lease/Аренда Фабричная 31.docx` | договор D972000001-01, DOCX | сумма с копейками; «в том числе НДС», «без учёта НДС»; штраф в процентах от месячной арендной платы «за каждое нарушение» и фиксированный штраф «за каждый случай» — не ставки |
| `lease/ДС аренда.pdf` | ДС D972000002-01, 1 стр. | короткое тире внутри номера договора в шапке; новая редакция пункта со ставкой с копейками и НДС «сверх указанной суммы»; изменение суммы в пункте без слов «изложить в редакции» (НДС берётся из изменяемого пункта); вступает в силу с подписания и распространяет действие на отношения с более ранней даты |
| `lease/scan_1002.pdf` | соглашение о расторжении D972000003-01, скан с шумом | расторжение с будущей даты (действует на 2026-10-30, расторгнут на 2027-02-01); OCR читает латинскую D номеров как цифру 0 |
